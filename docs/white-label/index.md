# White-label & licensing

windowsweep's source is public under the MIT licence. You can read it, build it and fork it today, and a licence does not change that. What a licence buys is the work MIT does not cover: the windowsweep team rebrands the programs, builds them, publishes them under your name and keeps them updated. It also gives you the right to use the windowsweep name and logo, which MIT does not grant.

Every licence is **non-exclusive**. There is no buyout: the code is already public, so there is nothing to hand over.

## What you can license

A licence is sold per group, and a group is offered only when windowsweep itself ships it:

| Group | What you get |
|---|---|
| Desktop app | The desktop window under your product name, as a setup `.exe` and an `.msi` |
| Command-line tool (npm) | The engine on npm under your package name or scope, run with `npx` |

There is no browser extension or phone app, so neither is offered. [What is delivered](./delivered.md) says exactly what each group contains.

## Prices

Each group has its own price, and two groups together take a bundle discount. The current figures are on the [white-label pricing page](https://windowsweep.aoneahsan.com/white-label/pricing), which reads them from the licensing service and shows that service's quote as the total. This documentation does not repeat them, so it cannot go out of date.
