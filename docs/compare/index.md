# Moving to windowsweep

**Last checked 7 November 2026.** One guide for each tool below: which sections do the same job, the commands in order, and what you should keep the other tool for. Each guide carries the facts it rests on, read from the maker's own pages, with the date.

Before you start, know two limits. windowsweep does not clear tracking cookies today: cookies, logins, history and Local Storage are left alone in every browser profile. And the desktop app's Free plan counts real runs each month. The [pricing page](https://windowsweep.aoneahsan.com/pricing) has the current number, and [Use a desktop plan](../plans.md) explains the count. The command line is never counted.
