> Last updated: 2026-09-08

Two lines in `docusaurus.config.ts` change when the CLI 1.2.0 release lands, and **not before**. Applying
either one early puts a version on a live public site that does not exist on npm, and the site's
`SoftwareApplication` JSON-LD is the surface answer engines read structurally - a wrong `softwareVersion`
there is a machine-readable false claim, not a typo.

**Apply both in one edit, after `windowsweep@1.2.0` is published**, then re-run `yarn build` and `yarn typecheck`.

## Change 1 - `TOOL_VERSION`

**File:** `docusaurus.config.ts` **line 20**

Current:

```ts
const TOOL_VERSION = '1.1.0';
```

Replacement:

```ts
const TOOL_VERSION = '1.2.0';
```

The constant has one definition and one consumer: `softwareVersion: TOOL_VERSION` at **line 135**, inside the
`SoftwareApplication` JSON-LD block. Nothing else reads it, so this single line is the whole change.
