windowsweep

windowsweep reclaims disk space on a Windows machine from caches, temp files, superseded tool releases and items you choose. It names paths before it touches them. Documents, credentials and browser state are protected. Section 19 can offer large or old files in Downloads and folders you add; it selects nothing for you.

Start with npx windowsweep --scan. It measures every target and deletes nothing.

The README is the short version; this folder is the manual.

What people ask before they run it​

How do I free up disk space on Windows without deleting anything important? Start with npx windowsweep --scan, which deletes nothing and measures what is present. The safe batch clears caches and temp files; personal files require you to choose them. Read the safety model before a real run.

Does this cleanup tool send my data anywhere? No. Cleanup never touches the network, and the engine's own code holds no network call: self-test check [9] greps its own source for HTTP and socket calls and fails the build if it finds any. Only sections 30, 31 and 32, for the rows you pick, ask Windows Update or winget to download; windowsweep itself sends nothing. The desktop application is a separate program: it sends usage and crash reports. There is no switch. In 1.1.0 no destination was configured in the build; from 1.2.0 all four are.
