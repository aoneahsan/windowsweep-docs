# Docusaurus configuration

## Front matter fields worth knowing

```yaml
---
title: Uploading files                    # required — page title + <title>
description: How uploads work and what…   # required — meta description + search snippet
tags: [api, uploads]                      # discovery
sidebar_position: 3                       # ordering within a category
sidebar_label: Uploads                    # shorter label in the sidebar
slug: /api/uploads                        # override the URL
keywords: [file upload, storage api]      # extra search terms
image: /img/social/uploads.png            # per-page OG image
draft: true                               # excluded from production builds
---
```

## Sidebar patterns

```ts
// sidebars.ts
const sidebars: SidebarsConfig = {
  apiSidebar: [
    'api/overview',
    {
      type: 'category',
      label: 'Endpoints',
      link: { type: 'generated-index' },   // a real landing page, not a dead node
      items: ['api/objects', 'api/emails'],
    },
  ],
};
```

`link: { type: 'generated-index' }` matters — a category with no link is a node users click and nothing
happens.

Autogenerated sidebars (`type: 'autogenerated'`) suit large, regularly-shaped folders; explicit sidebars suit
curated ordering. Do not mix within one section.

## Swizzling

```bash
yarn swizzle @docusaurus/theme-classic <Component> -- --wrap    # preferred
yarn swizzle @docusaurus/theme-classic <Component> -- --eject   # last resort
```

`--wrap` composes around the original and survives upgrades. `--eject` copies the whole implementation and
freezes it — every future Docusaurus fix to that component now bypasses you. Prefer wrapping; eject only when
wrapping genuinely cannot express the change, and note why in the file.

## Versioning

```bash
yarn docusaurus docs:version 2.0.0
```

Only version docs that ship alongside a versioned artefact (a package or an API). Versioning a marketing or
notebook site multiplies maintenance for no reader benefit.

## Redirects

```ts
plugins: [
  ['@docusaurus/plugin-client-redirects', {
    redirects: [{ from: '/docs/old-path', to: '/docs/new-path' }],
  }],
],
```

Client redirects are the fallback; a host-level 301 is better for SEO where the host supports it.

## Machine-readable surfaces for agents

- Serve raw `.md` and `.json` at stable URLs, viewable in the browser and downloadable.
- Where there is an API, publish `/openapi.json` — it is the machine truth, and it is what an agent should be
  told to read first.
- Provide an AI-integration page that states the base URL, auth header, the endpoint map, and the response
  envelope shape. Assume the reader is an agent implementing against it in one pass.
- Prerendering means crawlers and non-JS fetchers see real content — verify with a plain `curl` that the body
  is populated, not a shell.

## A client feature fed by build-time config refuses a build without it

windowsweep's docs ship a release gate whose Supabase URL and publishable key come from `.env.local` at build time.
A build with neither value went live on 2026-11-04 and the gate was dead for a day, silently. `docusaurus.config.ts`
now loads `.env.local`, then `.env` with `process.loadEnvFile` (first wins, so the specific file goes first; it
throws on a missing file, so check `existsSync` first) and throws when a production build lacks a required value.
